Tema de colores

Tamaño del texto

Agranda toda la app (texto, botones e íconos juntos, no solo las letras). Se guarda en este navegador; cada dispositivo puede tener el suyo.

Herramientas para operadores

Páginas móviles independientes. Comparte el enlace, o escanéalo desde una tablet / celular y agrégalo a la pantalla de inicio para usarlo como una app.

Instalar en el dispositivo

Android (Chrome): abre el enlace → menú ⋮ → “Agregar a pantalla principal”.

iPhone / iPad (Safari): abre el enlace → botón Compartir → “Agregar a inicio”.
